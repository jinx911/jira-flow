Jira-Flow 系统架构图

Hub-and-Spoke 多 Agent 协作开发工作流

Hub-and-Spoke 模式

  • Leader 永远不直接执行操作
  • 只做协调、决策和状态流转
  • 所有 Agent 间通信通过 Leader 路由
  • Agent 严禁直连其他 Agent

按需扩容策略

  • Phase 0: 核心团队 (req/planner/arch)
  • Gate 1 后: 按需创建开发团队
  • Phase 4 前: 创建 code-reviewer
  • Phase 5 前: 创建 tester

6 Gate 质量检查点

  • 每个 Phase 结束执行 Gate
  • 半自动: 用户确认后继续
  • 全自动: 质量达标自动通过
  • CRITICAL/HIGH 必须修复
