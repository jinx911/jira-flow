Jira-Flow 流程图

6 Phase + 6 Gate 全链路开发生命周期

TDD 铁律

  • 禁止无失败测试先写生产代码
  • RED: 写最小测试展示期望行为
  • GREEN: 写最小代码通过测试
  • REFACTOR: 清理，保持测试绿色

证据铁律

  • 任何完成声明必须有即时证据
  • 禁止: "应该能用了"
  • 每项验证: 命令 + 输出 + 退出码
  • Bug: 复现 + 预期 + 实际 + 证据

异常处理

  • 构建失败: dev 自修复 ≤2 次
  • 测试 Bug: 循环 ≤3 次
  • 超过上限: Leader 升级到用户
  • MCP 失败: 保存状态，恢复继续
